A two-day open for one-line worst AI advice, capped at 140 characters. Judged in private rounds on funniness, AI voice and tightness, with the funniest line taking the whole $2 pot.

> To fix the bug, delete the database and start over — debugging is just procrastination with extra steps.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network.
